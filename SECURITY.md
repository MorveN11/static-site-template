# Security Policy

Please report vulnerabilities privately, not in a public issue.

1. Open the repo's **Security** tab.
2. Click **Report a vulnerability** and describe the issue and steps to reproduce.

This is a static site template: relevant areas are `nginx.conf` (headers, CSP), the `Dockerfile` and `.github/workflows/`. Issues in third-party dependencies should be reported upstream.

Only `main` is supported.
